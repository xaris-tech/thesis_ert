# Photos

One top-down photo per target run, ground truth for block position.

Name each file after its run: `<run_id>.jpg`, e.g. `20261002-140411-ssim-saline.jpg`
(near E9). If a run has several photos, add a suffix: `-a`, `-b`.

A good photo is taken straight down, shows the whole tank with the E1 mark
visible, and ideally has a ruler in frame.
