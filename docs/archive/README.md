# Archive

arrived at, and are **not** current guidance. Do not build or wire from these.

For current information use `HANDOVER.md`, `CONTEXT.md`,
`PHASE_3A_PINOUT_TABLES.md`, `docs/chapter-3-methodology-draft.md` and
`docs/adr/`.
