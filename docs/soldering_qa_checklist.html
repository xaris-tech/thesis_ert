1. ESP32-S3 Microcontroller

Power & I2C

  • 3V3 → MCP4725 VDD, ADS1115 VDD, 4x MUX VCC
  • GND → All module GNDs
  • GPIO8 → I2C SDA (DAC & ADC)
  • GPIO9 → I2C SCL (DAC & ADC)

MUX_I_SRC (Source Current)

  • GPIO37 → MUX_I_SRC EN
  • GPIO4 → MUX_I_SRC S0
  • GPIO5 → MUX_I_SRC S1
  • GPIO6 → MUX_I_SRC S2
  • GPIO7 → MUX_I_SRC S3

MUX_I_RET (Return Current)

  • GPIO38 → MUX_I_RET EN
  • GPIO10 → MUX_I_RET S0
  • GPIO11 → MUX_I_RET S1
  • GPIO12 → MUX_I_RET S2
  • GPIO13 → MUX_I_RET S3

MUX_VP (Voltage Positive)

  • GPIO39 → MUX_VP EN
  • GPIO15 → MUX_VP S0
  • GPIO16 → MUX_VP S1
  • GPIO17 → MUX_VP S2
  • GPIO18 → MUX_VP S3

MUX_VN (Voltage Negative)

  • GPIO40 → MUX_VN EN
  • GPIO36 → MUX_VN S0
  • GPIO35 → MUX_VN S1
  • GPIO41 → MUX_VN S2
  • GPIO42 → MUX_VN S3

2. CD74HC4067 Multiplexers

MUX_I_SRC (Source Current)

  • VCC → ESP32 3V3
  • GND → System GND
  • SIG/COM → OPA2134PA Pin 5 Junction
  • C0 - C11 → Electrodes E1-E12 Bus

MUX_I_RET (Return Current)

  • VCC → ESP32 3V3
  • GND → System GND
  • SIG/COM → System GND (or Shunt Resistor)
  • C0 - C11 → Electrodes E1-E12 Bus

MUX_VP (Voltage Positive)

  • VCC → ESP32 3V3
  • GND → System GND
  • SIG/COM → ADS1115 A0
  • C0 - C11 → Electrodes E1-E12 Bus

MUX_VN (Voltage Negative)

  • VCC → ESP32 3V3
  • GND → System GND
  • SIG/COM → ADS1115 A1
  • C0 - C11 → Electrodes E1-E12 Bus

3. MCP4725 (DAC)

  • VDD → ESP32 3V3
  • GND → System GND
  • SDA → ESP32 GPIO8
  • SCL → ESP32 GPIO9
  • ADDR → GND
  • VOUT → Resistor R3 (5kΩ to OPA2134PA Pin 3)

4. ADS1115 (ADC)

  • VDD → ESP32 3V3
  • GND → System GND
  • SDA → ESP32 GPIO8
  • SCL → ESP32 GPIO9
  • ADDR → GND
  • A0 → MUX_VP SIG/COM
  • A1 → MUX_VN SIG/COM

5. OPA2134PA Current Pump

  • R1 (5kΩ) → Between Pin 2 and GND
  • R2 (100Ω) → Between Pin 1 and Pin 2
  • R3 (5kΩ) → Between DAC VOUT and Pin 3
  • R4 (100Ω) → Between Pin 7 and Pin 3
  • Rs (68Ω) → Between Pin 1 and Pin 5
  • Pin 4 (V-) → System GND (or Negative Supply)
  • Pin 6 (Inv B) → Tied directly to Pin 7
  • Pin 8 (V+) → Positive Supply (+9V)
  • Pin 5 Junction → MUX_I_SRC SIG/COM
