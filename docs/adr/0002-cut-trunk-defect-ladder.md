# Cut-trunk pilot runs a four-stage cumulative defect ladder in one session

Drilled defects are permanent, so the cut-trunk pilot cannot re-test a condition once passed. We therefore scan at every stage — intact, 3 cm side-sector hole, the same hole widened to 8 cm, then a separate 8 cm centre hole — and take the difference between *consecutive* stages, which isolates the single defect newly added at that step and makes the cumulative nature harmless. All four stages run in one continuous session with the twelve-electrode ring installed once and never re-seated, because a cut trunk loses moisture continuously and moisture is the dominant conductor in wood: a multi-day ladder would put global drying into every stage-to-stage difference, swamping the local defect signal. Both adjacent and opposite drive patterns run at every stage, since adjacent drive is weakest at the trunk centre where stage 4's defect sits, and a pattern only differences against the same pattern at the previous stage.

Success is pre-registered as the **sector match criterion**: at stages 3 and 4 the strongest reconstruction sector must match the drilled sector in at least 2 of 3 repeat runs. Stage 2 is declared exploratory in advance — it is sized near the resolution limit of a twelve-electrode ring, so either outcome is a finding about detection threshold rather than a pass or fail.

## Considered Options

- **Severity ladder only** (one location, growing defect) — gives the three category proxies but never tests whether reconstruction locates an anomaly in the correct sector.
- **Localisation ladder only** (side-sector then centre, per the original plan) — tests localisation but yields no severity grading for the health categories.
- **Two trunks, one experiment each** — both claims land without confounding, at roughly double the specimen prep and session time.

## Consequences

- A failed session partway through costs the specimen; the sequence must be rehearsed before the real trunk is used.
- Every top-drilled defect must extend at least one electrode spacing below the electrode band, or it never crosses the measurement plane.
- If an electrode contact degrades mid-ladder, the nail is not touched; whether to exclude that electrode is an analysis-time decision, which stays reversible.
- Stage 2 must not be reported as a failure if the 3 cm defect is undetected.
