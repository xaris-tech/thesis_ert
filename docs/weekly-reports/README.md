# Weekly reports

One status report per ISO week, from project start (June 2026) to now, named
`YYYY-Www-status.md`. Every report uses the same headings so weeks can be compared:

1. Summary
2. Circuit construction
3. Testing and verification
4. Scans
5. Difference imaging
6. Absolute imaging
7. Saline tank
8. Resistor ring
9. Wood discs
10. 3D-printed case
11. Risks and blockers
12. Plan for next week

"No change" under a heading means nothing in that area was recorded that week. The reports
were reconstructed on 2026-10-20 from git history, ADRs, session notes and `scans/index.csv`;
the evidence itself stays in `scans/runs/`, `exports/`, `phase3a_logs/` and `docs/adr/`.

The 3D-printed case was planned and made in W28–W34 and refitted in W37; its specifics
(dimensions, material, print settings) are still to be filled in.
